# horizon-porter 0.9.0

Mods with machines now play. This release comes out of porting Farmer's Delight, Macaw's Fences
and Walls, Stoneworks, Villagers Plus, Friends & Foes, Naturalist, Beautify and Advanced
Netherite, playing them in Horizon, and fixing every problem in the porter itself, so every mod
with the same pattern gets the fix too.

**Re-port your mods with this version** (`port --force`, or Port again in the app). Translated
functions are kept.

## Try a port in the game, automatically

- **`check`, and the app after every build**, opens a test world, places every block the mod
  adds, right-clicks the ones whose Java acts on a click (holding what the code asks for: its
  tools, an item it compares against), and reads the game's log. It ends with a plain count:
  "301 of 301 blocks work · 60 of 60 respond to a click".
- **A translated function the build refuses** is put back to its stub and the mod builds again,
  so one bad translation never blocks a mod.

## Blocks and items that act

- **Block entities** keep their saved values and item slots, and clicks reach them.
- **Ticks**: blocks that tick, random-tick (crops) or run `animateTick` (smoke, steam) do it in
  Horizon, with sounds and particles.
- **Placement, survival and comparators**: `onPlace`, `canSurvive`, comparator output and
  tooltips are ported.
- **Items that act in code** (`useOn`, `use`) are ported like block clicks: they know the player's
  facing, sneaking and creative mode, and can use up, wear or swap the stack in hand.
- **Foods and drinks** get their food values, how they're consumed and their effects.
- **Tools, weapons and armor** get their material's durability, damage, speed, repair item and
  enchantability, including tools whose settings spell their material out (Farmer's Delight's
  knives).

## Machines

- **Menus** are read by running the Java menu's constructor: every slot where Java puts it, which
  ones only take, where the player's inventory goes. Chest-like blocks open the vanilla menu.
- **Screens** draw with the mod's own texture and progress arrows. **Shift-click** runs the Java
  menu's `quickMoveStack`.
- **Recipes** of the mod's own types, and vanilla's cooking recipes, reach the machine's tick.
- **Renderers** draw what a block entity holds (the ingredient on a cutting board).

Checked in Horizon with Farmer's Delight: the cooking pot cooks beef stew on a campfire and needs
its bowl, the cutting board takes an ingredient, draws it and a knife cuts it, with the pieces
popping out beside the board.

## Horizon's new mod API (experimental)

`port --api` also writes the mod for Horizon's upcoming mod API (typed hooks and Parts, on the
[arismoko/horizon](https://github.com/arismoko/horizon) fork for now): blocks, items, block
entities, ticks, menus, screens, shift-clicks, renderers and drops. Farmer's Delight plays on it.
[docs/API-TRIAL.md](../API-TRIAL.md) has the details. It isn't in the app yet.

## Fixes

- A right click on a mod block was answered twice (main hand, then off hand), which made a
  cutting board take back what it was just given.
- A broken block entity drops what it held, as in Java.
- Linux: the app's window no longer stays blank white.
- Content: other mods' compatibility files are left out; crafting remainders (a bowl back from a
  stew) carry over.
